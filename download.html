⬇ Windows 다운로드 (ShinwooSaga.exe) 🌐 브라우저에서 바로 플레이 (설치 없이)
데스크톱판이 브라우저보다 렉이 적습니다.
처음 설치 / 실행
  1. 위 Windows 다운로드로 ShinwooSaga.exe를 받습니다 (단일 실행파일, 설치 과정 없음).
  2. 가급적 바탕화면이나 다운로드 폴더 등 쓰기 가능한 곳에 두세요 (자동 업데이트가 그 자리에 새 파일을 받습니다).
  3. 더블클릭해 실행. Windows가 “PC 보호” 경고를 띄우면 → 추가 정보 → 실행 (서명 안 된 개인 게임이라 그래요, 안전).
업데이트 (앱처럼 — 자동)
  1. 게임을 켜면 새 버전이 있을 때 타이틀에 “✨ 새 버전 — 지금 업데이트” 버튼이 뜹니다.
  2. 그 버튼만 누르면 게임이 알아서 최신 버전을 받아 교체하고 자동으로 재시작합니다. 웹페이지에 다시 올 필요 없어요.
  3. 세이브·랭킹은 클라우드 계정에 있어 그대로 이어집니다.
※ 자동 업데이트가 막히면(쓰기 권한 등) 이 페이지에서 다시 받아 기존 파일을 덮어써도 됩니다.
